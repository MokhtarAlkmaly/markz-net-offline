# النسخ الاحتياطي والاستعادة

توجد بطاقة **النسخ الاحتياطي والاستعادة** في صفحة الإعدادات. تنشئ ملف JSON واحداً
محلياً لبيانات الحساب، بما فيها:

- جداول البيانات الستة عشر: الطلاب، سجل الحفظ، بيانات الأعوام، المعلمون، مكافآت
  المعلمين، الداعمون، الجوائز، مصروفات الحفلات، الشهادات، المسابقات الداخلية
  والخارجية، المتابعة الشهرية، روابط المعلمين، الترسيلات الشهرية، سجل المجتمع،
  وبنك أسئلة الاختبارات.
- إعدادات الحساب المخزّنة بمفتاح خاص بالمستخدم.
- بيانات ملفات الوسائط نفسها (صور/فيديو) مع بياناتها الوصفية.

لا يتضمن الملف حسابات الدخول أو كلمات المرور أو أذونات الاطلاع أو بيانات المزامنة
القديمة. وإذا أشار سجل وسيط إلى ملف غير موجود محلياً، يُرفض إنشاء نسخة ناقصة.

## طريقة الاستعادة

1. اختر ملف JSON؛ يتحقق التطبيق من نوعه وإصداره ثم يعرض معاينة للأعداد قبل الكتابة.
2. أكد **تنفيذ الدمج** بعد مراجعة الطلاب الجدد والمطابقات والسجلات والإعدادات والوسائط.
3. لا تحذف الاستعادة أي بيانات حالية ولا تستبدل قيمة غير فارغة:
   - تُطابق أسماء الطلاب بعد التطبيع، وتُملأ الحقول الفارغة فقط. تُعاد مطابقة
     سجلات الطالب بمعرّفه المحلي، بما في ذلك بيانات الأعوام والحفظ والمتابعة.
   - تُدمج بقية الجداول بمفاتيحها الطبيعية، وتُملأ فراغات السجل المطابق دون
     إنشاء نسخة مكررة عند استعادة الملف مرة أخرى.
   - تُعاد كتابة ملكية الصفوف إلى الحساب الذي ينفّذ الاستعادة، وتُعاد تسمية
     مسارات الوسائط إلى مفاتيح محلية للحساب الهدف.
4. تُرفض الاستعادة أثناء الاطلاع على حساب آخر بوضع القراءة فقط.

الملف يحوي بيانات حساسة محلياً؛ خزّنه في مكان آمن. لا تُرسل البيانات إلى خادم.
اختبار الانحدار: `npm run test:backup`.
