# هوية المركز (الاسم والشعار) — استخدام التطبيق لأكثر من مركز

هذه الميزة تجعل التطبيق نفسه يخدم **أكثر من مركز**: كل حساب يكتب اسم مركزه
ويرفع شعاره من صفحة **الإعدادات**، فيظهران في كل الواجهة والكشوف المطبوعة بدل
اسم النسخة الافتراضي (`Markz Net`).

## 1) من أين تُضبط؟

**الإعدادات → هوية المركز (الاسم والشعار)**

| الحقل             | الوصف                                                                                       |
| ----------------- | ------------------------------------------------------------------------------------------- |
| اسم المركز        | الاسم الظاهر في الترويسات وصفحة الدخول وكشوف الطباعة.                                       |
| سطر الإشراف/الفرع | السطر الرسمي أسفل الاسم (مثل: `الإشراف - شرعب الرونة`).                                     |
| شعار المركز       | صورة تُختار من الجهاز (PNG/JPG/WebP/SVG/GIF) أو تُسحب وتُفلَت على المربّع، مع معاينة فورية. |

- تُصغَّر الصور تلقائياً إلى ضلع أقصى 640 بكسل وتُحوَّل إلى WebP (أو PNG إن لم
  يدعمه المتصفح) قبل الحفظ، فلا تتضخم قاعدة البيانات.
- زر **حفظ هوية المركز** يعتمد التغييرات، وزر **استعادة الافتراضي** يعيد
  الاسم والشعار المدمجين.
- داخل البطاقة معاينة حيّة لشكل الترويسة ولنص كشف الطباعة.

## 2) أين تظهر الهوية؟

- **الترويسات:** الشريط الجانبي، الصفحة الرئيسية، كل صفحات الأقسام
  (الحلقات، المتابعة الشهرية، المسابقات، الجوائز، الشهادات، المتبرعون،
  المصروفات، المستخدمون، المتأخرات، البحث…)، وصفحة تسجيل الدخول.
- **الطباعة:** كل الكشوف والتقارير (`activeCenterPrintTitle`) وشهادات
  المعلمين وتقارير الطلاب وبطاقة الطالب وكشوف المتأخرات وشهادات التكريم —
  وكذلك شعار المركز في أعلى كل كشف.
- **عنوان التبويب وأيقونته:** يُحدَّثان بالاسم والشعار المخصصين عند تشغيل
  التطبيق مع حفظ الهوية.
- علامة النسخة التقنية «`Markz Net — نسخة بلا إنترنت`» تبقى في الشارات
  الصغيرة وبعض الملفات الوصفية — فهي تمييز للنسخة المحلية، لا اسم مركز.

## 3) كيف تُخزَّن؟ (محلياً بالكامل)

| المكان                                                 | المحتوى                                               |
| ------------------------------------------------------ | ----------------------------------------------------- |
| `settings` في SQLite بمفتاح `<userId>:center_identity` | الهوية الكاملة (الاسم + الإشراف + الشعار كـ data URL) |
| `localStorage` بمفتاح `markznet.centerBrand`           | نسخة خفيفة تعرضها صفحة الدخول قبل تسجيل الدخول        |

- الهوية **خاصة بكل حساب** (كحالات الطلاب والأعمدة المخصصة)، فالمركز الذي
  يخصّص هويته لا يتأثر بغيره على الجهاز نفسه.
- في **وضع الاطلاع** على بيانات مستخدم آخر تظهر هوية صاحب البيانات، ولا
  يمكن تعديلها (تُرفض بـ `ReadOnlyViewError`).
- عند الدخول بحساب لم يخصّص هويته بعد، تُعرض هوية آخر مركز مُعرَّف على
  الجهاز (لتسهيل الإعداد)، وبمجرد الحفظ تصبح الهوية خاصة بالحساب.
- **حذف قاعدة البيانات** (من الحذف المتقدم) يمسح هوية الحساب؛ وتبقى نسخة
  الجهاز في `localStorage` ليظهر اسم المركز في صفحة الدخول.

## 4) في الشيفرة

| الملف                                       | الدور                                                                                |
| ------------------------------------------- | ------------------------------------------------------------------------------------ |
| `src/lib/center-brand.ts`                   | أنواع الهوية، الافتراضيات، النصوص المشتقة، معالجة ملف الشعار، وذاكرة الهوية النشطة   |
| `src/hooks/useCenterBrand.tsx`              | المزوّد الذي يحمّل الهوية ويوزّعها (`useCenterBrand`) ويحدّث عنوان التبويب والأيقونة |
| `src/components/CenterIdentitySettings.tsx` | بطاقة الإعدادات (الحقول + الشعار + المعاينة)                                         |
| `src/utils/storage.ts`                      | `loadCenterIdentity` / `saveCenterIdentity` / `resetCenterIdentity`                  |

### قاعدتان عند تعديل الواجهات أو التقارير

1. **داخل مكوّنات React:** استخدم الخطاف ولا تكتب الاسم نصاً:

   ```tsx
   const { name, logoUrl, headerLine, identity } = useCenterBrand();
   <img src={logoUrl} alt={name} />;
   ```

2. **داخل قوالب الطباعة (خارج React):** استخدم الدوال المتزامنة التي تقرأ
   الهوية النشطة:

   ```ts
   import { activeCenterPrintTitle, activeCenterLogoSrc } from "@/lib/center-brand";
   `<h1>${activeCenterPrintTitle()}</h1><img src="${activeCenterLogoSrc(logo)}" />`;
   ```

   الهوية النشطة تُحدَّث من المزوّد عند التحميل والحفظ، لذا لا حاجة لتمرير
   الاسم والشعار يدوياً في كل تقرير.

## 5) الاختبارات

```bash
npm run test:integration
```

يشمل الغلاف الجديد:

- حفظ وقراءة الاسم والإشراف والشعار لكل حساب، ورفض الشعار من رابط خارجي.
- نسخة الجهاز (`markznet.centerBrand`) وقراءتها بلا تسجيل دخول.
- عزل الهوية بين الحسابات، ومنع التعديل في وضع الاطلاع.
- تطبيع القيم والنصوص المشتقة وذاكرة قوالب الطباعة.
