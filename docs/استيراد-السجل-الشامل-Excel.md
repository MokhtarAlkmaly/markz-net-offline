# استيراد Excel للسجل الشامل (كل الأعوام)

صفحة **الطلاب** (`/students`) هي السجل الرسمي الموحّد لكل طلاب المركز عبر كل
الأعوام. من شريط أدوات الجدول يمكن:

| الزر               | الوظيفة                                                                 |
| ------------------ | ----------------------------------------------------------------------- |
| **استيراد Excel**  | يقرأ ملف `.xlsx` (أو `.csv`) ويحدّث السجل الشامل أو يضيف إليه.          |
| **إرشادات القالب** | نافذة تشرح الأعمدة والسلوك، وفيها تنزيل القالب ونتيجة آخر استيراد.      |
| **تصدير Excel**    | ينزّل السجل الحالي بنفس رؤوس القالب، فالملف المصدَّر يُستورد بلا تعديل. |

## 1) الأعمدة المعتمدة

القالب والتصدير يستخدمان الرؤوس نفسها:

`م` · `رقم القيد` · `اسم الطالب` · `الجنس` · `تاريخ هجري الالتحاق` ·
`الحفظ قبل الالتحاق` · `الحفظ التراكمي (آخر عام)` · `عام أول مسابقة` ·
`الأعوام المسجل بها` · `الحالة` · `السنة الدراسية وقت الالتحاق` ·
`رقم ولي الأمر` · `رقم الطالب` · `ملاحظات`

- `م` و`رقم القيد` يُهمَلان — الترقيم محلي ويُدار تلقائياً.
- أسماء الأعمدة تُطابَق بعد تطبيع عربي (الهمزات، التاء المربوطة، الأقواس،
  التشكيل، المسافات المتعددة)، فـ`الحفظ التراكمي` و`الحفظ التراكمي (آخر عام)`
  كلاهما مقبول.
- أي عمود مخصص مُعرَّف في «إدارة الأعمدة» يُطابَق بعنوانه نفسه ويُحفظ في
  `custom_fields` بمعرّف العمود.
- الأعمدة غير المعروفة تُتجاهل، والصف بلا عمود معروف يُرفض برسالة عربية.

## 2) قواعد الاستيراد

1. **المفتاح هو الاسم** بعد التطبيع (`normalizeStudentName` المستخدم نفسه في
   كشف الأسماء المكررة):
   - **اسم موجود** → يُحدَّث سجله، والاسم الأصلي المخزَّن لا يتغير.
   - **اسم جديد** → يُنشأ طالب جديد في السجل الشامل، ويُسجَّل في الأعوام المذكورة.
2. **الفراغ لا يدهس**: أي خلية فارغة في الملف تُبقي القيمة الحالية في
   التطبيق كما هي (الملاحظات، الأرقام، الأعمدة المخصصة...).
3. **الأعوام**: عمود `الأعوام المسجل بها` مفصول بفواصل عربية أو إنجليزية أو
   أسطر. كل عام يُسجَّل بصف `year_data` فيظهر في عمود «الأعوام المسجل بها».
   - الصيغة أربع خانات: `1441`، `1445`، ...
   - مسابقة عشر ذي الحجة تتبع عامها بلاحقة `D`: `1447D` (ويُفهم أيضاً
     `1447 ذ.ح` أو `1447هـ · عشر ذي الحجة`).
   - الأعوام تُرتَّب تصاعدياً وتُزال المكررات.
4. **الحفظ التراكمي**: قيمة `الحفظ التراكمي (آخر عام)` تُكتب في آخر عام مذكور
   في الملف، فيعرضها عمود «الحفظ التراكمي (آخر عام)» في الجدول.
5. **الأسماء المكررة داخل الملف** تُدمج في سجل واحد: الصف الأول هو الأصل
   وبقية الصفوف تكمل الحقول الفارغة فقط.
6. **النتيجة** تظهر في تنبيه أعلى أعلى الجدول: جديد / محدَّث / متخطى / أسماء
   مكررة دُمجت، مع قائمة ملاحظات الصفوف المرفوضة (بأرقام صفوف Excel).

## 3) الحماية والصلاحيات

- الكتابة تمر عبر طبقة التخزين نفسها (`saveStudent` / `saveYearData`)، فيسري
  عليها **عزل الحسابات** (`user_id`) و`guardWrite()` — أي أن الاستيراد في
  **وضع الاطلاع** على بيانات مستخدم آخر مرفوض.
- لا يمسّ الاستيراد أي جدول آخر: لا حذف لطلاب ولا أعوام، ولا تعديل على
  بيانات عام لم يُذكر في الملف.

## 4) في الشيفرة

| الملف                              | الدور                                                                   |
| ---------------------------------- | ----------------------------------------------------------------------- |
| `src/utils/studentExcelImport.ts`  | تحليل الصفوف + تطبيقها + القالب والإرشادات (بلا أي اعتماد على xlsx)     |
| `src/components/StudentsTable.tsx` | أزرار الاستيراد/القالب/التصدير، ونافذة الإرشادات والنتيجة، وقراءة الملف |
| `src/pages/Index.tsx`              | إعادة تحميل السجل والإحصاءات وشريط ملخص آخر استيراد                     |
| `src/utils/excel.ts`               | `loadXLSX` (تحميل كسول) و`saveWorkbook` (تنزيل/مشاركة)                  |

## 5) الاختبارات

```bash
npm run test:integration
```

تغطي مجموعة «استيراد Excel»:

- تطبيع الأعوام (`1447`، `1447D`، `1447 ذ.ح`، النصوص بلا عام) ومطابقة الرؤوس
  والأعمدة المخصصة وبناء القالب.
- التحليل: تنظيف المسافات، تجاهل الصفوف الفارغة، رفض الصف بلا اسم أو بأعمدة
  غير معروفة، دمج الصفوف المكررة بالاسم داخل الملف.
- التطبيق: تحديث المطابق بالاسم (بصيغة مطبَّعة مختلفة) دون دهس البيانات
  اليدوية ولا تغيير الاسم، وإنشاء الجديد، وتسجيل الأعوام، وكتابة الحفظ
  التراكمي في آخر عام، والعزل بين الحسابات.
